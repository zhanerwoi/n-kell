## Мүмкіндіктер
- 8 тәуелсіз тест: Holland RIASEC, Үлкен бестік, құндылықтар, мотивация, күшті жақтар, оқу тәсілдері, шешімге дайындық, жұмыс ортасы + 30 сұрақтық жедел тест
- Біртұтас профиль, түсіндірілетін мамандық ұсыныстары (салмақтарды баптауға болады), «бірінші таңдаудан тыс» мамандықтар
- 44 мамандық беті («Бұл мамандықтағы бір күн»), мамандықтар шайқасы, ҰБТ навигаторы, университет навигаторы
- 10 интерактивті симулятор, жеке жол картасы, ережеге негізделген кеңесші, прогресс және есептер, мұғалім панелі

## GitHub Pages-те жариялау
1. GitHub-та жаңа репозиторий аш (мысалы `n-kell`).
2. Осы папканы жүкте:
   ```bash
   git remote add origin https://github.com/<USERNAME>/n-kell.git
   git push -u origin main
   ```
3. Репозиторийде: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады: `https://<USERNAME>.github.io/n-kell/`

Сайт статикалық: сервер, база немесе build қажет емес. Кез келген статикалық хостингте (Netlify, Vercel, Cloudflare Pages) жұмыс істейді.

## Өзгерту
- Бастапқы файл — `page.html` және `assets/`. Өзгерткеннен кейін іске қос: `python3 build.py`
  Ол `index.html` (сайт) және `dist/n-kell.html` (интернетсіз ашылатын бір файл) жасайды.
- Мазмұн: `assets/data.js`, `assets/content.js`, `assets/content_prof.js`, `assets/tests.js`
- Аудармалар: `assets/i18n.js`, `assets/i18n2.js`
- Есептеу логикасы: `assets/engine.js` (DOM-сыз таза функциялар). Толығырақ: `ARCHITECTURE.md`

## Деректер және құпиялылық
- Барлық аккаунттар мен нәтижелер **тек пайдаланушының браузерінде** (localStorage) сақталады. Ешқандай деректер серверге жіберілмейді.
- Сол себепті мұғалім панелі бір ортақ компьютерде ғана жұмыс істейді. Бірнеше құрылғыда жұмыс істеу үшін сервер қажет (жоспар — `ARCHITECTURE.md`).
- Құпиясөз жергілікті қарапайым хэшпен сақталады — бұл қауіпсіз аутентификация емес.
- Тесттер диагноз қоймайды; бұл — өзін-өзі тануға арналған білім беру құралы.

## Жарияламас бұрын тексер
- ҰБТ пәндер комбинациялары ресми дереккөзбен тексерілмеген (сайтта солай белгіленген): `assets/content.js → NK.UNT_PROGRAMS`.
- Университет сайттарының сілтемелері мен бағдарламалар тізімі.
- Сенім телефоны нөмірлері (150, 112) — `assets/mentor.js`.
